## Meeting types

- **Planning:** Set the Sprint Goal and choose the work.
- **Check-in:** Share progress, blockers, and next steps.
- **Review:** Demonstrate completed work and record feedback.
- **Retro:** Record what went well, problems, and improvements.

Use Central Time for meeting dates and times when needed. Update this file
after the meeting and link any related GitHub issues or pull requests in the
notes or action items.
